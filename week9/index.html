Monday — Git basics

Git saves the history of my project on my computer. GitHub keeps a copy online so I can share it.

Command What it does
git initStarts a new repository (makes the .git folder)
git statusShows untracked, changed and staged files
git add .Puts changes in the staging area
git commit -m "..."Saves a snapshot with a message
git log --onelineShows the commit history
git checkout -b nameMakes a new branch and switches to it
git merge nameJoins a branch into the current one
git push / git pullUploads to / downloads from GitHub

Working directory → git add → staging area → git commit → local repo → git push → GitHub

Friday — GitHub Pages

This portfolio is deployed with GitHub Pages (Settings → Pages → Deploy from a branch → main → / (root)).

  • index.html has to be in the root of the repo
  • All links use relative paths like ../style.css, not /style.css
  • File names are lowercase because the server is case-sensitive
  • There is a custom 404 page for links that don't exist
