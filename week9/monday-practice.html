Week 9 Monday — Git & Version Control Practice

Complete these three hands-on exercises in order using your own computer and GitHub account.

Exercise 1: Create your first repository

Goal: Initialize a Git repository, create a file, and make your first commit.

  1. Create a folder named my-first-git and open a terminal in it.
  2. Initialize a repository with git init.
  3. Create an index.html file containing a simple heading.
  4. Run git status and identify the untracked file.
  5. Stage the file with git add index.html.
  6. Commit it with a descriptive message, for example git commit -m "Add initial HTML page".
  7. Run git log --oneline and confirm your commit appears.

Exercise 2: Create and merge a branch

Goal: Practice making a change on a feature branch and merging it into the main branch.

  1. From your practice repository, create and switch to a branch named feature-style.
  2. Create a style.css file with a basic CSS rule.
  3. Stage and commit the stylesheet on the feature branch.
  4. Switch back to main and observe that the branch's unmerged file is not present.
  5. Merge feature-style into main.
  6. Confirm style.css is now present on main.

Exercise 3: Push your repository to GitHub

Goal: Publish your practice repository to your own GitHub account.

  1. Create a new empty GitHub repository named git-exercise. Do not initialize it with a README.
  2. Connect your local repository using git remote add origin https://github.com/YOUR-USERNAME/git-exercise.git, replacing the placeholder with your username.
  3. Check the remote with git remote -v.
  4. Push your main branch using git push -u origin main.
  5. Open your repository on GitHub and confirm the files and commit are visible.
