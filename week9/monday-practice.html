Week 9 Monday — Git & Version Control Practice

Practice initializing a repository, committing files, using a feature branch, merging it, and pushing to GitHub.

Project files are ready: Open the Git practice project.

Exercise 1: Create your first repository

Goal: Initialize a Git repository, create a file, and make your first commit.

  1. Use the project files linked above, or copy them into a new folder named my-first-git.
  2. Open a terminal in that folder and run git init.
  3. Run git status and identify the untracked files.
  4. Stage the page with git add index.html, then commit using a descriptive message.
  5. Run git log --oneline and confirm your commit appears.

Exercise 2: Create and merge a branch

Goal: Practice making a change on a feature branch and merging it into the main branch.

  1. Create and switch to a branch named feature-style.
  2. Add or change a CSS rule in style.css.
  3. Stage and commit the stylesheet on the feature branch.
  4. Switch back to main, then merge feature-style.
  5. Confirm the stylesheet change is present on main.

Exercise 3: Push your repository to GitHub

Goal: Publish your practice repository to your own GitHub account.

  1. Create a new empty GitHub repository for the exercise, or use a repository you own.
  2. Connect your local repository with git remote add origin YOUR-REPOSITORY-URL.
  3. Verify the remote using git remote -v.
  4. Push your branch with git push -u origin main.
  5. Open GitHub and confirm the files and commit are visible.

Important: The practice project files are now in this portfolio. Branch creation, local commits, and a push from your computer still need to be performed in Git as part of the exercise; the site does not claim those local steps were run.
