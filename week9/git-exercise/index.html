WEEK 9 · MONDAY PRACTICE

My First Git Project

A small HTML and CSS project to use for the Git init, commit, branching, merge, and GitHub push exercises.

Practice checklist

  1. Initialize a repository for this project and inspect it with git status.
  2. Stage and commit this page as your first snapshot.
  3. Create a feature branch, add or adjust the stylesheet, commit it, and merge it back.
  4. Push your practice repository to a GitHub repository you own.

What this page demonstrates

This page and its stylesheet are the HTML/CSS files for the exercise. Adding them here does not itself run Git commands on your computer or create the separate branch/merge history. Follow the practice guide for those Git steps.
