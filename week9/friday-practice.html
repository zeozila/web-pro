Week 9 Friday — GitHub Pages & Deployment Practice

Use your own public GitHub repository. These exercises practice deploying and checking a static website.

Exercise 1: Enable GitHub Pages

Goal: Publish your repository as a live website.

  1. Open your repository on GitHub and select Settings, then Pages.
  2. Under Build and deployment, choose Deploy from a branch.
  3. Select the main branch and /(root) folder, then save.
  4. Wait for the deployment to finish and open the published URL shown in Pages settings.
  5. Confirm that your repository's index.html loads at the published URL.

Exercise 2: Check a 404 page

Goal: See what visitors get when they request a page that does not exist.

  1. Open your published site and add /this-does-not-exist.html to its URL.
  2. Observe the not-found page that appears.
  3. Check whether your repository already contains a 404.html file.
  4. Write down one way a custom not-found page could improve the visitor experience.

Exercise 3: Create a custom 404 page

Goal: Add a friendly not-found page to your site and deploy it.

  1. Create a 404.html file in the same folder as your root index.html.
  2. Add a clear “Page not found” message and a link back to your home page.
  3. Commit and push the new file to the branch used by GitHub Pages.
  4. After deployment, revisit a nonexistent URL and confirm your custom page appears.
